Ember Pact is an original duel card game: you face Ash, the Cinder Rival, across a table of four suits — Flame, Tide, Thorn and Star. Spend mana, play cards, and chain two cards of one suit in a turn to trigger Resonance: extra damage, healing, a draw, or bonus mana. Reduce Ash's Ember to zero before yours runs out.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — mouse and keyboard (1–7 select a card, Enter plays it, E ends your turn, R restarts, M mutes).
